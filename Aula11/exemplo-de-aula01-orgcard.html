Aprendendo Front-End

HTML

O HTML (HyperText Markup Language, ou Linguagem de Marcação de Hipertexto) é a linguagem padrão usada para criar e estruturar páginas na internet. Organiza o esqueleto de uma página web, dizendo ao navegador o que é um título, um parágrafo, uma imagem, um link, uma tabela ou um botão.

Conhecer o HTML

CSS

O CSS (Cascading Style Sheets ou Folhas de Estilo em Cascata) é uma linguagem de estilo usada para definir a aparência visual de páginas da web. Enquanto o HTML cria a estrutura e o conteúdo de um site, o CSS cuida do design, organizando cores, fontes, espaçamentos, layouts e responsividade.
